A dying phone battery's last text to its charger, in one line: it held on at 1% for six hours so its human could send one last text — and then watched the human charge the AirPods first. The program in `main.ts` holds the line, validates it (a single non-blank line of 1–200 characters, no trailing newline or padding), writes it to `/output/entry.txt`, and verifies the written file byte-for-byte before reporting its character and byte counts.

## Run it

```sh
node main.ts
```
